恢复与维护

恢复使用设备上的备份；编辑器中的文本不会改变。

开始使用

使用支持 Web Bluetooth 的 Chrome / Edge，通过 localhost 或 HTTPS 打开编辑器。设备需先烧录 MicroRT 固件。

  1. 给设备上电，等待启动完成。M5StickS3 会先滚动显示 3 位设备 ID。
  2. 打开右上角「连接」，点击「扫描并连接设备」，选择对应的 MicroRT ABC（ABC 为设备 ID）。
  3. 填入 USB 串口输出的 LUA_BLE_TOKEN，点击「验证令牌，启用上传」。浏览器会记住最近一次验证成功的令牌。
  4. 从左侧 Examples 加载适合板型的示例，或通过「文件 → 打开文件」载入自己的 Lua 脚本。Libraries 可查看库说明并插入 require，上传时自动收集依赖。
  5. 编辑代码，选择「上传后」的操作，再点击「↑ 上传 main.lua」。默认保存并立即运行；展开下方「设备输出」查看日志。

首次尝试可使用默认的用户灯示例：AtomS3-Lite 闪烁板载灯，M5StickS3 显示屏幕指示。

顶栏 ▶ 运行设备已保存的脚本；编辑后的代码需要重新上传。■ 停止脚本。

调试时，展开页面底部「Lua REPL」，点击「调试 main.lua」重新运行已保存脚本，再输入命令查看变量或调用函数。
